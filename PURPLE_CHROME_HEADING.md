# 💜 PURPLE METALLIC CHROME HEADING

## Overview
The NARD heading now features a badass purple metallic chrome effect inspired by the "Ancient Chrome" style - ultra shiny, dimensional, and eye-catching.

## Effect Breakdown

### 1. Chrome Gradient
```css
10-step gradient:
- Dark Purple (#3d1e5f) → Deep Purple (#5a2d82)
- Medium Purple (#7c3bad) → Bright Purple (#a855f7)
- Light Purple (#d8b4fe) → Near White (#f3e8ff)
- Then reverses back to create symmetry
```

### 2. Shimmer Animation
- 4-second infinite loop
- Background position shifts 200%
- Creates liquid metal movement
- Smooth linear timing

### 3. Multiple Drop Shadows
```css
Layer 1: 0 0 20px purple (bright glow)
Layer 2: 0 0 40px purple (outer glow)
Layer 3: 0 4px 10px black (depth shadow)
```

### 4. Text Shadows
```css
5 layers of shadows:
- Inner glow: Purple halos (10px, 20px, 30px)
- Depth shadows: Black shadows (2px, 5px, 15px)
- Creates 3D dimensional effect
```

### 5. Filters
- `brightness(1.4)` - Makes it shine brighter
- `contrast(1.5)` - Increases definition
- Combined with drop-shadow for maximum impact

### 6. Background Layer (::before)
- Dark purple gradient behind main text
- Animates in reverse direction
- Blur effect (2px)
- Creates depth and dimension

### 7. Glitch Effect Enhancement
- Purple chrome gradient on glitch layers
- Cyan and magenta color shifts
- Animated clip-path distortion
- Drop-shadow glows on glitch layers

### 8. Pulsing Glow
```css
3-second pulse animation:
- Alternates between normal and intense glow
- Uses drop-shadow filters
- Creates breathing effect
```
